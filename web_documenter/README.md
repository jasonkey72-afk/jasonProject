# 웹 본문 문서화 도구 (Chrome / Edge 확장)

웹 페이지 본문을 **스크롤 없이 한 번에** 읽어 문서 파일로 저장해 주는 브라우저 확장입니다.
페이지를 열고 버튼 한 번(또는 자동)으로 본문 전체가 문서가 되므로, 스크롤바를 내려가며
복사·붙여넣기를 반복할 필요가 없습니다.

## 해결하는 문제

| 기존 방식 | 이 도구 |
|---|---|
| 스크롤을 내리며 화면에 보이는 만큼 복사 → 붙여넣기 반복 | 페이지 DOM 전체를 한 번에 읽어 본문만 추출 |
| 메뉴·광고·사이드바·댓글까지 같이 붙어와서 다시 정리 | 본문 영역만 자동 판정, 부속 영역 제거 |
| 표·목록 서식이 깨져서 다시 손봄 | 표/목록/코드/인용을 서식 그대로 변환 |
| 그림은 따로 캡처해서 붙여넣기 | 본문 그림을 문서 안에 그대로 넣음 |
| 페이지마다 파일을 따로 만들어 관리 | **일괄**(모아서 한 문서) / **건 별**(즉시 파일) 선택 |

## 저장 방식 두 가지

- **일괄 저장** — 필요한 페이지들을 계속 "담기" 해 두었다가, 마지막에 한 번에 저장합니다.
  - `하나로 합쳐 저장`: 목차가 붙은 문서 **한 개**로 저장
  - `건별 파일로 저장`: 담아 둔 항목을 **각각의 파일**로 한 번에 저장 (한 폴더에 모아서)
- **건 별 저장** — 담는 즉시 그 페이지 하나가 파일로 바로 저장됩니다.

여기에 **페이지를 열 때마다 자동 수집** 옵션을 켜면, 링크를 클릭해 페이지를 이동할 때마다
본문이 자동으로 목록에 담깁니다. 자료를 쭉 훑어본 뒤 마지막에 한 번만 저장하면 됩니다.

## 문서 형식

| 형식 | 쓰임 | 그림 |
|---|---|---|
| `Markdown (.md)` | 사내 위키/LLM 적재/텍스트 편집기. 표·목록·제목 구조가 그대로 유지됨 (기본값) | 포함 |
| `PDF (.pdf)` | 결재·배포·보관용. 아래 "PDF 저장 방법" 참고 | 포함 |
| `Word 문서 (.doc)` | 보고서로 바로 편집. Word 로 열림 (표·제목 서식 유지) | 포함 |
| `웹 문서 (.html)` | 브라우저로 열어 보관 | 포함 |
| `텍스트 (.txt)` | 서식 없이 내용만 필요할 때 | 설명만 |

그림은 문서 파일 안에 데이터로 들어가므로, 원본 사이트에 접속하지 못하는 PC 에서
문서를 열어도 그림이 그대로 보입니다. (파일 하나로 완결)

### PDF 저장 방법

PDF 를 고르면 **인쇄 창**이 열립니다. **대상**을 **"PDF로 저장"** 으로 고른 뒤
저장을 누르면 됩니다. 파일 이름은 문서 제목으로 미리 채워집니다.

> 확장에서 PDF 를 직접 만들면 한글 글꼴 전체를 프로그램에 넣어야 해 파일이 수십 MB 로
> 커지고 표·그림 배치도 화면과 달라집니다. 브라우저의 인쇄 기능을 쓰면 **화면에 보이는
> 그대로**, 한글도 깨지지 않고 저장됩니다. 그래서 클릭 한 번이 더 필요한 방식을 택했습니다.

- 문서마다 **자동으로 쪽이 나뉘고**, 여러 건을 합치면 맨 앞에 **목차**가 들어갑니다.
- `건별 파일로 저장` 을 고르면 문서 수만큼 탭이 열리고, **탭을 볼 때마다** 인쇄 창이
  하나씩 열립니다.
- `건 별 저장` + `자동 수집` 을 함께 켠 경우에는 인쇄 창이 계속 뜨지 않도록
  자동 수집한 페이지는 **목록에만 담깁니다.**

## 1. 설치 방법 (부서원 각자 1회)

크롬 웹스토어 등록 없이, 폴더째로 설치합니다. 관리자 권한은 필요 없습니다.
배포용 파일은 [`package/web_documenter_v1.1.1.zip`](package/web_documenter_v1.1.1.zip)
하나이며, 압축 안에 같은 내용의 `설치방법.txt` 가 들어 있습니다.

1. ZIP 을 풀어 `web_documenter` 폴더를 PC에 둡니다. (예: `C:\사내도구\web_documenter`)
   - 폴더 안에 `manifest.json` 이 보여야 합니다. 압축 파일이면 먼저 압축을 풉니다.
2. 브라우저 주소창에 아래 주소를 입력합니다.
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 우측 상단(Edge 는 좌측 하단)의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드** (Edge: **압축 풀린 확장 로드**) 클릭 → 1번 폴더 선택
5. 도구 모음에 파란 문서 아이콘이 생기면 완료입니다. (안 보이면 퍼즐 모양 아이콘 → 고정)

> 폴더를 지우거나 옮기면 확장도 사라집니다. 지워지지 않을 경로에 두세요.

### 새 버전으로 업데이트할 때 (중요)

새 ZIP 을 받아 폴더의 파일을 덮어썼다면, **반드시 확장을 새로고침해야 합니다.**

1. `chrome://extensions` (Edge 는 `edge://extensions`) 를 엽니다.
2. **웹 본문 문서화 도구** 카드의 **새로고침(↻)** 버튼을 누릅니다.

새로고침을 하지 않으면 **화면(팝업)은 새 버전인데 실제 동작은 옛 버전**이라,
예를 들어 PDF 를 골라도 예전 형식(.md)으로 저장되고 인쇄 창이 뜨지 않습니다.
이 상태가 되면 팝업 맨 위에 빨간 **"확장 새로고침이 필요합니다"** 안내가 표시되고,
팝업 맨 아래에서 현재 실행 중인 버전을 확인할 수 있습니다.

## 2. 사용 방법

1. 문서화할 페이지를 엽니다.
2. 도구 모음의 확장 아이콘을 클릭합니다.
3. **저장 방식**(일괄/건 별)과 **문서 형식**을 고릅니다. (한 번 고르면 계속 유지됩니다)
4. **이 페이지 담기** 클릭 — 또는 단축키 `Alt+Shift+S`
5. 여러 건을 담았다면 **하나로 합쳐 저장** 또는 **건별 파일로 저장** 클릭

여러 페이지를 연달아 볼 때는 **페이지를 열 때마다 자동 수집**을 켜 두고 평소처럼
링크를 클릭해 가며 읽기만 하면 됩니다. 담긴 건수는 아이콘 위 숫자로 표시됩니다.

### 옵션

| 옵션 | 설명 |
|---|---|
| 본문 그림 포함 | 본문의 그림을 문서 안에 넣습니다. 메뉴 아이콘·추적용 1x1 픽셀은 자동으로 걸러집니다 |
| 페이지를 열 때마다 자동 수집 | 페이지 이동 시 자동으로 본문을 담습니다. (수동 클릭 불필요) |
| 저장 전 페이지 끝까지 자동 스크롤 | "더보기"·무한 스크롤처럼 스크롤해야 내용이 붙는 페이지 대응. 자동으로 끝까지 훑고 원래 위치로 돌아옵니다 (최대 15초) |
| 같은 주소는 중복 수집 안 함 | 같은 페이지를 두 번 담지 않습니다 |

## 3. 저장 결과

브라우저의 **다운로드 폴더** 아래에 저장됩니다.

```
다운로드/
└─ 웹문서화/
   ├─ 20260820_143012_3분기 결산 프로세스 안내.md      ← 건 별 저장
   ├─ 모음_20260820_143530_7건.md                      ← 일괄(하나로 합쳐)
   └─ 모음_20260820_143530/                            ← 일괄(건별 파일로)
      ├─ 001_3분기 결산 프로세스 안내.md
      └─ 002_구매 발주 지침.md
```

각 문서에는 **제목 / 출처 URL / 수집 시각 / 분량**이 머리말로 붙고,
합쳐 저장한 문서에는 맨 앞에 **목차**가 들어갑니다.

> 브라우저에 따라 다운로드 파일명에 한글을 허용하지 않는 경우가 있습니다.
> 이때는 자동으로 영문 이름(`WebDocs/collection_20260820_143530_7items.md`)으로 저장되며,
> 파일 **내용의 한글은 어느 경우에도 그대로**입니다.

## 4. 동작 원리와 한계

- 화면에 보이는 부분이 아니라 **페이지 전체의 DOM**을 읽으므로 스크롤이 필요 없습니다.
- 본문 판정은 ① 흔히 쓰이는 본문 컨테이너(`article`, `.board-view`, `#bo_v_con` 등) 확인 →
  ② 문단이 가장 많이 모여 있는 블록을 점수로 선택하는 순서로 이루어집니다.
- 메뉴·배너·사이드바·댓글·페이징·푸터, 화면에 표시되지 않는 숨김 영역, 스크립트는 제외합니다.
- 로그인이 필요한 사내 시스템도 **이미 로그인된 브라우저 안에서** 동작하므로 그대로 수집됩니다.
- 그림은 페이지와 같은 로그인 상태로 내려받아 문서 안에 넣습니다.
  - 가로 1400px 를 넘거나 400KB 를 넘는 그림은 자동으로 줄여 넣습니다. (문서 크기 관리)
  - 가로·세로가 모두 40px 미만인 아이콘과 1x1 추적 픽셀은 넣지 않습니다.
  - 움직이는 그림(GIF)과 벡터(SVG)는 원본 그대로 넣습니다.
  - 문서 하나에 넣는 그림 총량은 25MB 로 제한하며, 넘으면 나머지는 주소로만 연결합니다.
  - "본문 그림 포함"을 끄면 원본 주소로만 연결합니다.
- 한계
  - 다른 사이트에서 불러온 `iframe` 내부 내용은 브라우저 보안 정책상 읽을 수 없습니다.
  - 본문/부속 영역 구분이 특이한 사이트에서는 일부가 빠지거나 더 붙을 수 있습니다.
    이럴 때는 형식을 `HTML`로 저장하면 원본 구조에 더 가깝게 남습니다.
  - 그림이 많은 페이지는 담는 데 몇 초가 걸리고 문서 파일도 커집니다.

## 5. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| "일반 웹페이지(http/https)에서만 사용할 수 있습니다" | `chrome://`, 확장 관리 페이지, 로컬 파일 등에서는 동작하지 않습니다. 일반 웹페이지에서 사용하세요 |
| "본문으로 인식할 내용을 찾지 못했습니다" | 본문이 그림/`iframe`으로만 되어 있는 페이지입니다. 텍스트가 있는 페이지에서 사용하세요 |
| 내용 일부가 빠짐 | "저장 전 페이지 끝까지 자동 스크롤"을 켜고 다시 담아 보세요 |
| 메뉴·댓글이 같이 들어옴 | 사이트 구조상 본문과 구분이 어려운 경우입니다. 저장 후 해당 부분만 지워 사용하세요 |
| Word에서 열 때 "형식이 다릅니다" 안내가 뜸 | `.doc` 는 Word 가 읽는 HTML 문서입니다. **예**를 누르면 정상적으로 열립니다 |
| **PDF를 골랐는데 `.md` 로 저장되고 인쇄 창이 안 뜸** | 파일만 교체하고 확장을 새로고침하지 않은 상태입니다. `chrome://extensions` 에서 **새로고침(↻)** 을 누르세요 (위 "업데이트할 때" 참고) |
| PDF를 골랐는데 파일이 안 생김 | 인쇄 창에서 **대상**을 **"PDF로 저장"** 으로 바꿔야 합니다. 프린터로 되어 있으면 종이로 인쇄됩니다 |
| 인쇄 창이 안 뜸 | 열린 탭 위쪽의 **[PDF로 저장 (인쇄)]** 버튼을 누르세요 |
| 건별 PDF에서 뒤쪽 탭이 조용함 | 그 탭을 클릭해 화면에 띄우면 인쇄 창이 열립니다 |
| 그림이 안 들어감 | 팝업에서 "본문 그림 포함"을 켜세요. `.txt` 형식에는 그림이 들어가지 않습니다 |
| 문서 파일이 너무 큼 | 그림이 포함된 문서입니다. 그림이 필요 없으면 "본문 그림 포함"을 끄세요 |
| 자동 수집이 동작하지 않음 | 팝업에서 옵션이 켜져 있는지 확인하세요. 페이지 로딩 완료 후 약 1초 뒤에 담깁니다 |
| 확장 설치가 정책으로 막힘 | 회사 정책(그룹 정책)으로 확장 설치가 제한된 경우입니다. 전산 담당자에게 `ExtensionInstallAllowlist` 등록을 요청하세요 |
| 아이콘 숫자가 남아 있음 | 아직 저장하지 않고 담아 둔 건수입니다. 저장하거나 "목록 비우기"를 누르세요 |

## 6. 개발자용: 검증 스크립트

실제 Chromium 에 확장을 로드해 수집 → 변환 → 저장까지 자동으로 확인합니다.

```bash
cd web_documenter
npm install --no-save playwright
npx playwright install chromium   # 브라우저가 없을 때만
node test/run_test.mjs
```

`test/fixtures` 의 가상 게시판·무한 스크롤 페이지를 대상으로 본문 추출 정확도(표/목록/코드/
링크·그림 변환, 메뉴·광고·댓글·아이콘 제거), 자동 스크롤, 중복 방지, 5개 형식 저장,
그림 포함/축소, PDF 인쇄 흐름(팝업 버튼 경로 포함), 일괄/건별 저장, 자동 수집, 팝업 동작,
버전 불일치 방어까지 71개 항목을 점검합니다. 결과 문서와 인쇄 미리보기는 `test/out/` 에
남습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 정의(권한, 아이콘, 단축키) |
| `content.js` | 페이지 안에서 본문을 찾아 Markdown/HTML/텍스트로 변환 |
| `background.js` | 수집 목록 관리, 자동 수집, 문서 생성 및 파일 저장 |
| `popup.html/css/js` | 아이콘 클릭 시 뜨는 조작 화면 |
| `print.html/js` | PDF 저장용 인쇄 페이지 |
| `설치방법.txt` | 배포본에 함께 들어가는 설치 안내 (메모장용) |
| `package.bat` | 배포용 ZIP 새로 만들기 (코드 수정 후 실행) |
| `package/` | 배포용 ZIP 결과물 |
| `test/` | Playwright 기반 검증 스크립트와 시험용 페이지 |
