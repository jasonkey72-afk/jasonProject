====================================================================
 웹 본문 문서화 도구 - 설치 방법 (Chrome / Edge)
====================================================================

웹 페이지 본문 전체를 스크롤 없이 한 번에 문서로 저장하는 도구입니다.
설치 프로그램(exe)을 실행하는 방식이 아니라, 브라우저에 폴더를 등록하는
방식입니다. 관리자 권한이 필요 없고 3분이면 끝납니다.


[1] 압축 풀기
--------------------------------------------------------------------
  받은 ZIP 파일을 지워지지 않을 위치에 풀어 주세요.
  예) C:\사내도구\web_documenter

  * 폴더 안에 manifest.json 파일이 보이면 정상입니다.
  * 이 폴더를 나중에 지우거나 옮기면 도구도 같이 사라집니다.
    바탕화면/다운로드 폴더는 피해 주세요.


[2] 브라우저에 등록
--------------------------------------------------------------------
  1) 브라우저 주소창에 아래 주소를 입력하고 이동합니다.
       - Chrome  : chrome://extensions
       - Edge    : edge://extensions

  2) "개발자 모드" 를 켭니다.
       - Chrome  : 화면 오른쪽 위
       - Edge    : 화면 왼쪽 아래

  3) "압축해제된 확장 프로그램을 로드" 버튼을 누릅니다.
       - Edge 에서는 "압축 풀린 확장 로드" 로 표시됩니다.

  4) [1] 에서 압축을 푼 web_documenter 폴더를 선택합니다.

  5) 주소창 오른쪽 도구 모음에 파란색 문서 아이콘이 생기면 설치 완료입니다.
     (아이콘이 안 보이면 퍼즐 조각 모양 아이콘을 누른 뒤 "고정" 하세요)


[3] 사용 방법
--------------------------------------------------------------------
  1) 문서로 남기고 싶은 페이지를 엽니다.
  2) 도구 모음의 파란 문서 아이콘을 클릭합니다.
  3) 저장 방식과 문서 형식을 고릅니다. (한 번 고르면 계속 유지됩니다)

       [저장 방식]
        - 일괄 저장  : 여러 페이지를 담아 두었다가 마지막에 한 번에 저장
                       (하나로 합쳐 저장 / 건별 파일로 저장 중 선택)
        - 건 별 저장 : 담는 즉시 페이지 하나가 파일로 바로 저장

       [문서 형식]
        - Markdown(.md) / Word(.doc) / 웹문서(.html) / 텍스트(.txt)

  4) "이 페이지 담기" 클릭 (단축키: Alt + Shift + S)
  5) 여러 건을 담았다면 "하나로 합쳐 저장" 또는 "건별 파일로 저장" 클릭

  * "페이지를 열 때마다 자동 수집" 을 켜 두면, 평소처럼 링크를 클릭해
    가며 읽기만 해도 이동할 때마다 본문이 자동으로 담깁니다.
    다 본 뒤에 한 번만 저장하면 됩니다.

  * "저장 전 페이지 끝까지 자동 스크롤" 은 "더보기" 를 눌러야 내용이
    계속 붙는 페이지에서 켜 주세요.


[4] 저장 위치
--------------------------------------------------------------------
  브라우저의 "다운로드" 폴더 아래 "웹문서화" 폴더에 저장됩니다.

    다운로드\웹문서화\20260820_143012_3분기 결산 프로세스 안내.md
    다운로드\웹문서화\모음_20260820_143530_7건.md

  각 문서에는 제목 / 출처 주소 / 수집 시각이 머리말로 붙고,
  합쳐서 저장한 문서에는 맨 앞에 목차가 들어갑니다.


[5] 자주 있는 문제
--------------------------------------------------------------------
  - "일반 웹페이지에서만 사용할 수 있습니다" 라고 나옵니다
      => chrome:// 로 시작하는 설정 화면이나 확장 관리 페이지에서는
         동작하지 않습니다. 일반 웹페이지에서 사용해 주세요.

  - 내용 일부가 빠집니다
      => "저장 전 페이지 끝까지 자동 스크롤" 을 켜고 다시 담아 보세요.

  - Word 로 열 때 "형식이 다릅니다" 안내창이 뜹니다
      => .doc 파일은 Word 가 읽는 HTML 문서입니다.
         "예" 를 누르면 정상적으로 열립니다.

  - 개발자 모드 / 확장 설치가 막혀 있습니다
      => 회사 정책(그룹 정책)으로 제한된 경우입니다.
         전산 담당자에게 확장 허용 목록 등록을 요청해 주세요.

  - 파일 이름이 영문으로 저장됩니다
      => 브라우저가 파일명에 한글을 허용하지 않는 경우 자동으로 영문
         이름으로 저장됩니다. 파일 안의 내용은 한글 그대로입니다.


[6] 참고
--------------------------------------------------------------------
  - 로그인이 필요한 사내 시스템도, 이미 로그인한 브라우저 안에서
    동작하므로 별도 로그인 없이 그대로 수집됩니다.
  - 다른 사이트에서 불러온(iframe) 영역의 내용은 브라우저 보안 정책상
    읽을 수 없습니다.
  - 수집한 내용은 이 PC 안에서만 처리되며, 외부로 전송되지 않습니다.

  자세한 설명은 같은 폴더의 README.md 파일을 참고하세요.
