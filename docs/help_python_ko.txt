이 PC 에서 Python 을 찾지 못했습니다.
실행파일(exe)을 만들려면 Python 3.9 이상이 필요합니다.

 1) https://www.python.org/downloads/ 에서 Windows용 설치 파일을 받습니다.
 2) 설치 화면 맨 아래의 "Add python.exe to PATH" 를 반드시 체크합니다.
 3) 설치가 끝나면 이 창을 닫고, 이 배치 파일을 다시 실행합니다.

이미 설치했는데도 같은 메시지가 나온다면 PATH 에 등록되지 않은 것입니다.
Python 설치 파일을 다시 실행해 "Modify" -> "Add python.exe to PATH" 를
켜 주시거나, PC 를 다시 시작한 뒤 시도해 주세요.

참고: 이 안내는 담당자가 exe 를 만들 때만 필요합니다.
      완성된 exe 를 받는 부서원은 Python 을 설치할 필요가 없습니다.
