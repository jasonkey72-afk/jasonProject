# "클릭했더니 새 탭이 열렸는데, 다음 단계에서 버튼을 못 찾습니다" 해결 가이드

> 1단계: 웹사이트를 연다 → 2단계: 버튼을 누른다(**새 탭이 열림**) → 3단계: 새 탭의 버튼 클릭
> → `NoSuchElementException` / "요소를 찾지 못했습니다"

이 문서는 프레임워크(Selenium / Playwright / CDP)에 상관없이 적용할 수 있게 썼습니다.
jobScenario 사용자는 **5장**만 보면 됩니다.

---

## 1. 결론부터

**새 탭이 열려도 자동화의 시선은 원래 탭에 그대로 있습니다.**
브라우저 화면에는 새 탭이 보이니까 "열렸는데 왜 못 찾지?" 싶지만,
코드가 보고 있는 문서(document)는 여전히 1번 탭입니다.

즉 **요소를 찾는 문제가 아니라 "어느 탭을 보고 있는가"의 문제**입니다.
선택자를 아무리 고쳐도 해결되지 않습니다. 여기서 시간을 많이 뺏깁니다.

## 2. 먼저 이것부터 확인하세요 (3분)

3단계 실패 직전에 **열려 있는 탭 목록을 찍어 봅니다.** 원인이 바로 갈립니다.

```python
# Selenium
print("탭 수:", len(driver.window_handles))
for h in driver.window_handles:
    driver.switch_to.window(h)
    print("  -", driver.title, "|", driver.current_url)
```

결과에 따라:

| 결과 | 원인 | 가야 할 곳 |
|---|---|---|
| 탭이 **2개 이상**이고 원하는 화면이 보인다 | 탭 전환만 안 된 것 | 3장 |
| 탭이 **1개뿐**이다 | 새 탭이 아직 안 열렸거나 차단됨 | 4장 |
| 탭은 2개인데 원하는 화면이 **비어 있다** | 새 탭 로딩이 안 끝남 | 3장 (로딩 대기) |

## 3. 탭이 열렸는데 못 찾는 경우

### 3-1. 새 탭으로 전환한다 (가장 기본)

```python
# Selenium — 클릭 전 탭 수를 기억해 두고, 늘어날 때까지 기다렸다가 전환
from selenium.webdriver.support.ui import WebDriverWait

before = driver.window_handles          # 2단계 클릭 "전"에 저장
driver.find_element(By.LINK_TEXT, "상세보기").click()

WebDriverWait(driver, 30).until(lambda d: len(d.window_handles) > len(before))
new_tab = [h for h in driver.window_handles if h not in before][-1]
driver.switch_to.window(new_tab)
WebDriverWait(driver, 30).until(
    lambda d: d.execute_script("return document.readyState") == "complete")

# 이제부터 3단계 진행
```

**흔한 실수 3가지**

1. `driver.window_handles[-1]` 을 바로 쓴다
   → 목록 순서가 생성 순서라는 보장이 없습니다. **클릭 전/후 차집합**으로 고르세요.
2. 전환한 뒤 **로딩을 안 기다린다**
   → 전환은 됐는데 아직 빈 문서라 또 못 찾습니다. `readyState` 를 꼭 기다리세요.
3. 전환 후 **iframe 안을 안 본다**
   → 새 탭 안의 요소가 iframe 안에 있으면 `switch_to.frame()` 이 또 필요합니다.

### 3-2. 새 탭 안에서도 iframe 을 뒤진다

새 탭으로 옮겼는데도 못 찾으면 십중팔구 iframe 입니다.

```python
def find_in_all_frames(driver, by, value, depth=0):
    """현재 문서 -> 모든 iframe 을 깊이 우선으로 훑는다."""
    els = driver.find_elements(by, value)
    if els:
        return els[0]
    if depth > 3:
        return None
    frames = driver.find_elements(By.CSS_SELECTOR, "iframe, frame")
    for i in range(len(frames)):
        frames = driver.find_elements(By.CSS_SELECTOR, "iframe, frame")  # 매번 다시 읽는다
        driver.switch_to.frame(frames[i])
        found = find_in_all_frames(driver, by, value, depth + 1)
        if found:
            return found
        driver.switch_to.parent_frame()
    return None
```

### 3-3. 가장 강력한 방법 — "모든 탭을 뒤진다"

탭 번호를 맞히려 하지 말고 **찾을 때까지 모든 탭을 훑는 것**이 실무에서 제일 안정적입니다.
탭이 몇 번째에 열리든, 몇 초 뒤에 열리든 상관없어집니다.

```python
def find_anywhere(driver, by, value, timeout=20):
    """모든 탭 × 모든 프레임에서 찾고, 찾은 탭에 머무른다."""
    end = time.time() + timeout
    while time.time() < end:
        for handle in reversed(driver.window_handles):   # 최근 탭부터
            driver.switch_to.window(handle)
            driver.switch_to.default_content()
            el = find_in_all_frames(driver, by, value)
            if el:
                return el                                 # 그 탭에 머무른 채 반환
        time.sleep(0.5)
    raise NoSuchElementException(
        "어느 탭에서도 찾지 못했습니다: %s=%s / 열린 탭 %d개"
        % (by, value, len(driver.window_handles)))
```

## 4. 탭이 아예 안 열리는 경우

### 4-1. 늦게 열린다 (가장 흔함)

버튼이 서버 응답을 기다렸다가 `window.open()` 을 부르는 사이트가 많습니다.
클릭 직후 1~2초만 기다리면 놓칩니다. **20~30초까지 기다리세요.**

### 4-2. 팝업 차단에 막혔다

자동화가 **JavaScript 로 클릭**했을 때(`element.click()` 대신 `execute_script("arguments[0].click()")`)
브라우저가 "사용자가 누른 게 아니다"라고 판단해 새 탭을 막을 수 있습니다.
로그에 아무 오류도 없이 그냥 탭이 안 열립니다.

- **Selenium**: 가능하면 JS 클릭 대신 **진짜 클릭**(`el.click()`)을 쓰세요.
  가려져서 안 되면 `scrollIntoView` 후 다시 시도 → 그래도 안 될 때만 JS 클릭.
- **CDP 직접 제어**: `Runtime.evaluate` / `Runtime.callFunctionOn` 에
  **`userGesture: true`** 를 넣으면 사람이 누른 것으로 취급되어 차단되지 않습니다.
- 프로필 설정으로 팝업을 허용해 두는 것도 방법입니다.

### 4-3. 새 탭이 아니라 같은 탭에서 이동했다

`target="_blank"` 가 없으면 같은 탭에서 화면만 바뀝니다.
이때는 탭 전환이 필요 없고, **URL 이 바뀔 때까지 기다렸다가** 진행하면 됩니다.

```python
old_url = driver.current_url
click(...)
WebDriverWait(driver, 30).until(lambda d: d.current_url != old_url)
```

### 4-4. 새 탭이 아니라 별도 창(popup)이다

Selenium 은 창도 `window_handles` 에 넣어 주므로 3장 방법이 그대로 통합니다.

## 5. jobScenario 를 쓰는 경우

**v1.3.0 부터는 대부분 아무것도 안 하셔도 됩니다.**
현재 탭에서 못 찾으면 **열려 있는 다른 탭까지 자동으로 찾아보고** 그 탭으로 옮겨 갑니다.

```
· 현재 탭에 없어 다른 탭에서 찾았습니다 → '결재 상세' 탭으로 이동합니다.
```

그래도 불안정하면 **2단계와 3단계 사이에** 아래 단계를 하나 넣으세요.

| 동작 | 값 | 대기 시간 |
|---|---|---|
| **새 탭 열릴 때까지 기다렸다가 이동** | (비워둠) | 30 |
| **새 탭 열릴 때까지 기다렸다가 이동** | `결재 상세` (제목 일부) | 30 |
| **탭 전환** | `-1` (마지막) 또는 제목 일부 | 10 |

- 이미 새 탭으로 옮겨진 뒤라면 이 단계는 **아무 일도 하지 않으므로** 넣어 두어도 안전합니다.
- 원래 탭으로 돌아가려면 **탭 전환** 에 `0` 또는 원래 탭 제목 일부를 넣으세요.
- 실패하면 `%LOCALAPPDATA%\jobScenario\failures` 에 그 순간의 **화면·HTML** 이 남습니다.
  거기서 "어느 탭이었는지"를 바로 확인할 수 있습니다.

## 6. 최종 점검표

3단계가 실패할 때 위에서부터 순서대로 확인하세요.

- [ ] 실패 직전 **탭 목록**을 찍어 봤다 (2장)
- [ ] 탭이 2개 이상이면 **차집합**으로 새 탭을 골랐다 (`[-1]` 로 찍지 않았다)
- [ ] 전환 후 **`readyState === "complete"`** 를 기다렸다
- [ ] 새 탭 안의 **iframe** 도 뒤졌다
- [ ] 탭이 1개뿐이면 **20~30초**까지 기다려 봤다
- [ ] **JS 클릭 때문에 팝업이 차단**된 건 아닌지 확인했다 (4-2)
- [ ] 그래도 안 되면 **모든 탭 × 모든 프레임 탐색**(3-3)으로 바꿨다
