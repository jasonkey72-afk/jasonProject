# 새 탭 문제 — 코드 수정 부분

첨부: **`tab_fix.py`** (이 파일만 프로젝트에 넣으면 됩니다. 추가 설치 없음)

---

## 0단계. 먼저 이것부터 (필수, 1분)

3단계가 실패하는 자리 **바로 앞**에 두 줄을 넣고 한 번 돌려 주세요.
**출력 결과에 따라 고칠 곳이 달라집니다.**

```python
from tab_fix import debug_tabs
debug_tabs(driver)          # <-- 3단계 실패 직전에 넣기
```

출력 예:

```
============================================================
열린 탭: 2개
  [0] 사내 포털 | https://portal.company.com <-- 지금 보고 있는 탭
       (이 탭 안에 iframe 1개)
  [1] 결재 상세 | https://portal.company.com/detail
============================================================
```

| 출력 결과 | 원인 | 고칠 곳 |
|---|---|---|
| 탭이 **2개 이상**, 원하는 화면이 목록에 보임 | 탭 전환이 안 된 것 | **수정 1** |
| 탭이 **1개뿐** | 새 탭이 안 열림 (팝업 차단 의심) | **수정 2** |
| 탭 목록에 원하는 화면이 **아예 없음** | 다른 브라우저 창에 열림 | **수정 3** |

## 수정 1. 탭이 2개 이상인 경우 → **한 줄만 바꾸면 됩니다**

### 변경 전

```python
# 3단계 — 여기서 NoSuchElementException 발생
driver.find_element(By.XPATH, "//button[text()='최종승인']").click()
```

### 변경 후

```python
from tab_fix import click_anywhere        # 파일 맨 위에 추가

# 3단계 — 모든 탭 x 모든 프레임에서 찾아 클릭한다
click_anywhere(driver, By.XPATH, "//button[normalize-space()='최종승인']")
```

이게 전부입니다. **탭 전환 코드를 직접 쓸 필요가 없습니다.**
탭이 몇 번째에 열리든, 몇 초 뒤에 열리든, iframe 안에 있든 상관없어집니다.

> `text()` 대신 `normalize-space()` 를 쓴 것도 같이 바꿔 주세요.
> 버튼 글자 앞뒤에 공백·줄바꿈이 있으면 `text()='최종승인'` 은 매칭되지 않습니다.
> 이것만으로 해결되는 경우도 많습니다.

### 클릭이 아니라 입력/읽기라면

```python
from tab_fix import find_anywhere

el = find_anywhere(driver, By.ID, "opinion")   # 찾은 탭에 머무른 상태로 반환
el.send_keys("확인함")
```

### 탭 전환을 명시적으로 하고 싶다면 (선택)

```python
from tab_fix import wait_new_tab

before = driver.window_handles                      # 2단계 클릭 "전"에 저장
driver.find_element(By.LINK_TEXT, "상세보기").click()  # 2단계

wait_new_tab(driver, before, timeout=30)            # 새 탭 열릴 때까지 대기 + 전환
driver.find_element(By.XPATH, "//button[normalize-space()='최종승인']").click()
```

## 수정 2. 탭이 1개뿐인 경우 → **JS 클릭을 없애세요**

2단계 클릭을 `execute_script` 로 하고 있으면 브라우저가
"사람이 누른 게 아니다"라고 판단해 **새 탭을 오류 없이 조용히 차단**합니다.
로그에 아무것도 안 남아서 원인을 찾기 어렵습니다.

### 변경 전

```python
el = driver.find_element(By.ID, "detailBtn")
driver.execute_script("arguments[0].click();", el)   # <-- 팝업이 차단됨
```

### 변경 후

```python
el = driver.find_element(By.ID, "detailBtn")
driver.execute_script("arguments[0].scrollIntoView({block:'center'});", el)
el.click()                                            # <-- 진짜 클릭
```

가려져서 `el.click()` 이 실패한다면 위 `click_anywhere()` 를 쓰세요
(스크롤 후 재시도까지 자동으로 합니다).

### 그래도 탭이 안 열리면 — 팝업 차단 해제

```python
from selenium.webdriver.chrome.options import Options   # Edge 는 EdgeOptions

options = Options()
options.add_experimental_option("prefs", {
    "profile.default_content_setting_values.popups": 1,   # 팝업 허용
})
driver = webdriver.Chrome(options=options)
```

### 늦게 열리는 경우

서버 응답을 기다렸다가 여는 사이트가 많습니다. **30초까지** 기다려 보세요.

```python
click_anywhere(driver, By.XPATH, "...", timeout=30)
```

## 수정 3. 탭 목록에 아예 없는 경우

자동화가 조종하는 브라우저가 **아니라 다른 브라우저 창**에 열린 것입니다.
탭을 아무리 뒤져도 나오지 않습니다. 아래를 확인하세요.

```python
# 1) 이미 실행 중인 브라우저에 붙어 있지는 않은가
#    사용자가 쓰던 Edge 창과 자동화 창이 다른 프로세스면 서로 안 보입니다.

# 2) 사이트가 새 "창"을 여는 경우 -> window_handles 에 잡히므로 수정 1 로 해결됨

# 3) 사이트가 외부 프로그램/프로토콜(예: ms-excel:, custom://)을 호출하는 경우
#    -> 브라우저 밖이라 Selenium 으로는 제어 불가. 다른 접근이 필요합니다.
```

## 검증 결과

첨부한 `tab_fix.py` 는 실제 브라우저(Selenium + Chromium)로 **7건 전부 통과**했습니다.

```
PASS  방법A: 늦게 열린 새 탭에서 클릭      (3초 뒤 열리는 탭)
PASS  방법A: 즉시 열린 새 탭에서 클릭
PASS  방법B: wait_new_tab 후 평소대로
PASS  iframe 안 요소 탐색
PASS  새 탭에 있어도 원래 탭 요소 클릭
PASS  제목으로 탭 전환
PASS  없는 요소 -> 오류 + 원래 탭 복귀
```

## 함수 요약

| 함수 | 용도 |
|---|---|
| `debug_tabs(driver)` | 열린 탭 전부 출력 (원인 진단) |
| `click_anywhere(driver, by, value, timeout=30)` | 모든 탭에서 찾아 클릭 |
| `find_anywhere(driver, by, value, timeout=30)` | 모든 탭에서 찾아 반환(입력·읽기용) |
| `wait_new_tab(driver, before_handles, timeout=30)` | 새 탭 대기 후 전환 |
| `switch_tab_by(driver, "제목일부")` | 제목/주소로 탭 전환 |
| `find_in_frames(driver, by, value)` | 현재 탭의 모든 iframe 탐색 |
