# 사내 LLM 업무용 파일 변환 도구 모음

사내 LLM 챗봇 등 "특정 파일 형식만 허용"되는 업무 환경에서 쓸 수 있도록 만든
Windows용 변환 프로그램 모음입니다.

- [Excel → PDF 변환기](#excel--pdf-변환기): Excel 파일을 PDF로 변환
- [이미지 OCR 변환기](#이미지-ocr-변환기): 그림 파일(jpg/png 등) 속 글자를 텍스트로 추출 (이미지 첨부가 안 되는 환경에서 사용)

---

## Excel → PDF 변환기

사내 LLM 적재 등 "PDF 파일만 허용"되는 업무 환경을 위해, Excel 파일(xlsx/xlsm/xls)을
**본문 내용 그대로**(서식·표·한글 포함) PDF로 변환해 주는 Windows용 프로그램입니다.

### 핵심 특징

- **원본 파일 무손상**: Excel 파일을 읽기 전용으로 열고 절대 저장하지 않습니다. 변환이 끝나면 저장하지 않고 닫으므로 원본은 100% 그대로 유지됩니다.
- **내용/서식 그대로 보존**: 실제 설치된 Microsoft Excel 엔진으로 "인쇄하듯" PDF를 생성하므로, 셀 서식·병합·표·한글 폰트가 깨지지 않습니다.
- **일괄 변환**: 파일을 여러 개 선택하거나 폴더째로 추가하면 각각 별도의 PDF로 변환됩니다.
- **간단한 배포**: 빌드 후 exe 파일 하나만 부서원들에게 나눠주면 됩니다. (Python 설치 불필요)

### 동작 원리 및 필수 조건

이 프로그램은 Microsoft Excel을 자동화(COM)하여 변환하므로,
**exe를 실행하는 PC에 Microsoft Excel이 설치되어 있어야 합니다.**
사내 PC는 대부분 Excel이 설치되어 있으므로 별도 설치 없이 바로 사용할 수 있습니다.
(Excel이 없는 PC에서는 실행 시 안내 메시지가 표시됩니다.)

### 1. 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build.bat
```

더블클릭하거나 명령 프롬프트에서 실행하면 됩니다. 완료되면
`dist\Excel_to_PDF_변환기.exe` 파일이 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해서 배포하면 됩니다. (배포받는 사람은 Python을 설치할
필요가 없고, Excel만 있으면 됩니다.)

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build.bat`을 Windows PC에서 한 번 실행해 exe를 만들어야 합니다.

### 2. 사용 방법 (부서원)

1. `Excel_to_PDF_변환기.exe` 실행
2. **파일 추가...** 또는 **폴더 추가...** 로 변환할 Excel 파일을 목록에 담기
3. 저장 위치 선택 (원본과 같은 폴더 / 다른 폴더)
4. 필요하면 "인쇄 시 한 페이지 폭에 맞추기" 체크 (열이 잘리지 않도록 자동 축소, 기본 켜짐)
5. **PDF로 변환 시작** 클릭
6. 진행 로그에서 파일별 성공/실패 확인

각 Excel 파일은 같은 이름의 `.pdf` 파일로 변환됩니다 (예: `보고서.xlsx` → `보고서.pdf`).

### 3. 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python excel_to_pdf_converter.py
```

### 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "Microsoft Excel을 찾을 수 없습니다" | 해당 PC에 MS Excel이 설치되어 있지 않음. Excel 설치 필요 |
| 특정 파일만 실패 | 암호 보호된 파일이거나, 다른 프로그램에서 이미 열려 있는 파일일 수 있음. 파일을 닫고 재시도 |
| 한글이 깨져 보임 | 발생하지 않아야 정상 (Excel 자체 렌더링 사용). 발생 시 원본 파일의 폰트가 PC에 설치되어 있는지 확인 |

## 이미지 OCR 변환기

그림 파일(jpg/jpeg/png/bmp/tiff/gif/webp)을 **이미지 첨부가 불가능한 업무용 LLM 챗봇**에
붙여넣을 수 있도록, 이미지 속 글자를 OCR로 인식해 텍스트로 추출해 주는 Windows용 프로그램입니다.

### 핵심 특징

- **화면에서 바로 복사**: 변환 후 목록에서 이미지를 클릭하면 인식된 텍스트가 미리보기에 나타나고, 버튼 클릭 한 번으로 클립보드에 복사할 수 있습니다. 파일로 저장하지 않고 바로 챗봇 창에 붙여넣기만 해도 됩니다.
- **일괄 변환**: 이미지를 여러 개 선택하거나 폴더째로 추가하면 한 번에 모두 인식합니다.
- **한글 지원**: 한국어+영어 동시 인식을 기본으로 지원합니다 (한국어만/영어만 선택도 가능).
- **파일 저장 옵션**: 필요하면 이미지와 같은 이름의 `.txt` 파일로 각각 저장하거나, 모든 결과를 하나의 텍스트 파일로 합쳐서 저장할 수 있습니다.
- **간단한 배포**: 빌드 후 exe 파일 하나만 부서원들에게 나눠주면 됩니다. (Python 설치 불필요)

### 동작 원리 및 필수 조건

이 프로그램은 오픈소스 OCR 엔진인 **Tesseract-OCR**을 사용해 이미지 속 글자를 인식합니다.
**exe를 실행하는 PC에 Tesseract-OCR이 설치되어 있어야 합니다.**

1. https://github.com/UB-Mannheim/tesseract/wiki 에서 Windows용 설치파일을 내려받아 설치합니다.
2. 설치 화면의 "Additional language data"에서 **Korean(kor)**을 함께 체크하면 한글 인식이 가능해집니다. (기본은 영어만 포함되어 있는 경우가 많습니다.)
3. 설치 후 별다른 설정 없이 프로그램을 실행하면 자동으로 Tesseract를 찾습니다. 못 찾을 경우 안내 메시지가 표시됩니다.

> OCR 인식률은 이미지 해상도/화질에 따라 달라집니다. 글자가 작거나 사진이 흐릿하면 인식이 부정확할 수 있습니다.

### 1. 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build_ocr.bat
```

더블클릭하거나 명령 프롬프트에서 실행하면 됩니다. 완료되면
`dist\이미지_OCR_변환기.exe` 파일이 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해서 배포하면 됩니다. (배포받는 사람은 Python을 설치할
필요가 없고, Tesseract-OCR만 설치하면 됩니다.)

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build_ocr.bat`을 Windows PC에서 한 번 실행해 exe를 만들어야 합니다.

### 2. 사용 방법 (부서원)

1. `이미지_OCR_변환기.exe` 실행 (실행 PC에 Tesseract-OCR 설치 필요)
2. **이미지 추가...** 또는 **폴더 추가...** 로 변환할 이미지 파일을 목록에 담기
3. 필요하면 **인식 언어**를 선택 (기본: 한국어+영어)
4. **텍스트로 변환 시작** 클릭
5. 완료되면 목록에서 이미지를 클릭 → 오른쪽 미리보기에서 텍스트 확인
6. **이 텍스트 클립보드에 복사** 클릭 후, LLM 챗봇 창에 붙여넣기

파일로도 저장하고 싶다면 "저장 옵션"에서 개별 `.txt` 저장 및/또는 통합 텍스트 파일 저장을 선택하면 됩니다.

### 3. 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python image_ocr_converter.py
```

### 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "Tesseract-OCR 엔진을 찾을 수 없습니다" | 해당 PC에 Tesseract-OCR이 설치되어 있지 않음. 위 링크에서 설치 필요 |
| 한글이 깨지거나 인식이 안 됨 | 설치 시 Korean(kor) 언어 데이터를 선택하지 않았을 가능성. Tesseract 재설치 시 "Additional language data"에서 Korean 체크 |
| 인식 결과가 부정확함 | 이미지 해상도가 낮거나 글자가 기울어져 있으면 정확도가 떨어짐. 가능하면 정면에서 찍은 고화질 이미지 사용 |
