# 파일 변환기 모음 (File format converter pgm)

사내 업무용 Windows 변환 프로그램 모음입니다. 각각 exe 하나로 빌드해서
부서원들에게 나눠주면 됩니다. (배포받는 사람은 Python 설치 불필요)

| 프로그램 | 하는 일 | 소스 | 빌드 |
|---|---|---|---|
| Excel → PDF 변환기 | xlsx/xlsm/xls 를 서식 그대로 PDF로 | `excel_to_pdf_converter.py` | `build.bat` |
| MP4 → GIF 변환기 | 용량 큰 동영상을 움직이는 GIF로 | `mp4_to_gif_converter.py` | `build_mp4_to_gif.bat` |

---

# 1. MP4 → 움직이는 GIF 변환기

용량이 큰 동영상(MP4/AVI/MOV/MKV 등)을 **움직이는 GIF**로 변환합니다.
메신저·문서·게시판처럼 동영상을 못 올리는 곳에 짧은 장면을 붙여 넣을 때 사용합니다.

## 핵심 특징

- **원본 무손상**: 동영상 파일은 읽기만 하며 절대 변경하지 않습니다. 결과 GIF는 별도 파일로 저장되고, 같은 이름이 이미 있으면 `이름_1.gif` 로 저장하므로 기존 파일을 덮어쓰지 않습니다.
- **고화질 변환**: ffmpeg의 2단계 팔레트 방식(palettegen/paletteuse)을 사용합니다. 영상마다 최적 색상표를 따로 만들어 쓰기 때문에, 같은 용량에서 일반 변환보다 훨씬 깨끗합니다.
- **목표 용량 자동 맞추기**: "10MB 이하"처럼 지정해 두면 그 용량이 될 때까지 가로 크기와 프레임 수를 단계적으로 낮춰가며 자동으로 다시 변환합니다.
- **구간 잘라내기**: 시작 시간·길이를 지정해 긴 영상에서 필요한 장면만 GIF로 만들 수 있습니다.
- **일괄 변환 / 취소**: 파일 여러 개 또는 폴더째 추가해 한 번에 변환할 수 있고, 진행 중 취소할 수 있습니다.
- **별도 설치 불필요**: 변환 엔진(ffmpeg)이 exe 안에 함께 들어갑니다.

## GIF는 원래 용량이 큽니다 (중요)

GIF는 압축 효율이 동영상보다 훨씬 나쁜 포맷이라, **10초짜리 영상도 설정에 따라 수십 MB**가 될 수 있습니다.
용량을 줄이는 순서는 다음과 같습니다.

1. **길이를 줄이기** (가장 효과가 큽니다) — 필요한 5~10초 구간만 지정
2. **가로 크기 줄이기** — 480px 이하 권장
3. **FPS 줄이기** — 10fps면 충분히 자연스럽습니다
4. **화질을 "작게(색상 64)"로** 변경

잘 모르겠으면 기본값(가로 480px / 10fps / 목표 용량 10MB)을 그대로 두고 변환하면 됩니다.

## 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build_mp4_to_gif.bat
```

완료되면 `dist\MP4_to_GIF_변환기.exe` 가 생성됩니다. **이 exe 파일 하나만** 배포하면 됩니다.
ffmpeg가 함께 들어가므로 exe 용량은 100MB 내외입니다.

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build_mp4_to_gif.bat`을 Windows PC에서 한 번 실행해 exe를 만들어야 합니다.

## 사용 방법 (부서원)

1. `MP4_to_GIF_변환기.exe` 실행
2. **파일 추가...** 또는 **폴더 추가...** 로 동영상을 목록에 담기
3. GIF 설정 지정
   | 항목 | 설명 | 기본값 |
   |---|---|---|
   | 가로 크기(px) | 세로는 비율에 맞춰 자동 조정. `0`은 원본 크기 | 480 |
   | 초당 프레임(FPS) | 높을수록 부드럽고 용량이 큼 (10~15 권장) | 10 |
   | 화질 | 팔레트 색상 수 (높음 256 / 보통 128 / 작게 64) | 보통 |
   | 무한 반복 재생 | 끄면 한 번만 재생하고 멈춤 | 켜짐 |
   | 시작 시간 / 길이(초) | 비워두면 영상 전체 | 비어 있음 |
   | 목표 용량 이하로 자동 조절 | 초과 시 크기·FPS를 낮춰 재변환 | 켜짐 / 10MB |
4. 저장 위치 선택 (원본과 같은 폴더 / 다른 폴더)
5. **GIF로 변환 시작** 클릭 — 진행률과 파일별 결과 용량이 로그에 표시됩니다

각 동영상은 같은 이름의 `.gif` 로 저장됩니다 (예: `회의영상.mp4` → `회의영상.gif`).

## 개발/테스트용으로 직접 실행하기

```bat
pip install imageio-ffmpeg
python mp4_to_gif_converter.py
```

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "동영상 변환 엔진(ffmpeg)을 찾을 수 없습니다" | 개발용 실행 시 발생. `pip install imageio-ffmpeg` 실행 (exe로 배포하면 발생하지 않음) |
| GIF 용량이 너무 큼 | 위 "GIF는 원래 용량이 큽니다" 참고. 구간 길이 → 가로 크기 → FPS 순으로 줄이기 |
| 목표 용량까지 줄지 않음 | 영상이 너무 길기 때문입니다. 시작 시간/길이로 구간을 짧게 지정 |
| 변환이 오래 걸림 | 고화질 2단계 변환이라 원본이 크면 시간이 걸립니다. 가로 크기를 먼저 줄이면 훨씬 빨라집니다 |
| 특정 파일만 실패 | 손상된 파일이거나 영상 트랙이 없는 파일일 수 있습니다. 로그의 오류 메시지 확인 |

# 2. Excel → PDF 변환기

사내 LLM 적재 등 "PDF 파일만 허용"되는 업무 환경을 위해, Excel 파일(xlsx/xlsm/xls)을
**본문 내용 그대로**(서식·표·한글 포함) PDF로 변환해 주는 Windows용 프로그램입니다.

## 핵심 특징

- **원본 파일 무손상**: Excel 파일을 읽기 전용으로 열고 절대 저장하지 않습니다. 변환이 끝나면 저장하지 않고 닫으므로 원본은 100% 그대로 유지됩니다.
- **내용/서식 그대로 보존**: 실제 설치된 Microsoft Excel 엔진으로 "인쇄하듯" PDF를 생성하므로, 셀 서식·병합·표·한글 폰트가 깨지지 않습니다.
- **일괄 변환**: 파일을 여러 개 선택하거나 폴더째로 추가하면 각각 별도의 PDF로 변환됩니다.
- **간단한 배포**: 빌드 후 exe 파일 하나만 부서원들에게 나눠주면 됩니다. (Python 설치 불필요)

## 동작 원리 및 필수 조건

이 프로그램은 Microsoft Excel을 자동화(COM)하여 변환하므로,
**exe를 실행하는 PC에 Microsoft Excel이 설치되어 있어야 합니다.**
사내 PC는 대부분 Excel이 설치되어 있으므로 별도 설치 없이 바로 사용할 수 있습니다.
(Excel이 없는 PC에서는 실행 시 안내 메시지가 표시됩니다.)

## 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build.bat
```

더블클릭하거나 명령 프롬프트에서 실행하면 됩니다. 완료되면
`dist\Excel_to_PDF_변환기.exe` 파일이 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해서 배포하면 됩니다. (배포받는 사람은 Python을 설치할
필요가 없고, Excel만 있으면 됩니다.)

## 사용 방법 (부서원)

1. `Excel_to_PDF_변환기.exe` 실행
2. **파일 추가...** 또는 **폴더 추가...** 로 변환할 Excel 파일을 목록에 담기
3. 저장 위치 선택 (원본과 같은 폴더 / 다른 폴더)
4. 필요하면 "인쇄 시 한 페이지 폭에 맞추기" 체크 (열이 잘리지 않도록 자동 축소, 기본 켜짐)
5. **PDF로 변환 시작** 클릭
6. 진행 로그에서 파일별 성공/실패 확인

각 Excel 파일은 같은 이름의 `.pdf` 파일로 변환됩니다 (예: `보고서.xlsx` → `보고서.pdf`).

## 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python excel_to_pdf_converter.py
```

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "Microsoft Excel을 찾을 수 없습니다" | 해당 PC에 MS Excel이 설치되어 있지 않음. Excel 설치 필요 |
| 특정 파일만 실패 | 암호 보호된 파일이거나, 다른 프로그램에서 이미 열려 있는 파일일 수 있음. 파일을 닫고 재시도 |
| 한글이 깨져 보임 | 발생하지 않아야 정상 (Excel 자체 렌더링 사용). 발생 시 원본 파일의 폰트가 PC에 설치되어 있는지 확인 |
