# Excel → PDF 변환기

사내 LLM 적재 등 "PDF 파일만 허용"되는 업무 환경을 위해, Excel 파일(xlsx/xlsm/xls)을
**본문 내용 그대로**(서식·표·한글 포함) PDF로 변환해 주는 Windows용 프로그램입니다.

## 핵심 특징

- **원본 파일 무손상**: Excel 파일을 읽기 전용으로 열고 절대 저장하지 않습니다. 변환이 끝나면 저장하지 않고 닫으므로 원본은 100% 그대로 유지됩니다.
- **내용/서식 그대로 보존**: 실제 설치된 Microsoft Excel 엔진으로 "인쇄하듯" PDF를 생성하므로, 셀 서식·병합·표·한글 폰트가 깨지지 않습니다.
- **일괄 변환**: 파일을 여러 개 선택하거나 폴더째로 추가하면 각각 별도의 PDF로 변환됩니다.
- **간단한 배포**: 빌드 후 exe 파일 하나만 부서원들에게 나눠주면 됩니다. (Python 설치 불필요)

## 동작 원리 및 필수 조건

이 프로그램은 Microsoft Excel을 자동화(COM)하여 변환하므로,
**exe를 실행하는 PC에 Microsoft Excel이 설치되어 있어야 합니다.**
사내 PC는 대부분 Excel이 설치되어 있으므로 별도 설치 없이 바로 사용할 수 있습니다.
(Excel이 없는 PC에서는 실행 시 안내 메시지가 표시됩니다.)

## 1. 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build.bat
```

더블클릭하거나 명령 프롬프트에서 실행하면 됩니다. 완료되면
`dist\Excel_to_PDF_변환기.exe` 파일이 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해서 배포하면 됩니다. (배포받는 사람은 Python을 설치할
필요가 없고, Excel만 있으면 됩니다.)

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build.bat`을 Windows PC에서 한 번 실행해 exe를 만들어야 합니다.

## 2. 사용 방법 (부서원)

1. `Excel_to_PDF_변환기.exe` 실행
2. **파일 추가...** 또는 **폴더 추가...** 로 변환할 Excel 파일을 목록에 담기
3. 저장 위치 선택 (원본과 같은 폴더 / 다른 폴더)
4. 필요하면 "인쇄 시 한 페이지 폭에 맞추기" 체크 (열이 잘리지 않도록 자동 축소, 기본 켜짐)
5. **PDF로 변환 시작** 클릭
6. 진행 로그에서 파일별 성공/실패 확인

각 Excel 파일은 같은 이름의 `.pdf` 파일로 변환됩니다 (예: `보고서.xlsx` → `보고서.pdf`).

## 3. 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python excel_to_pdf_converter.py
```

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "Microsoft Excel을 찾을 수 없습니다" | 해당 PC에 MS Excel이 설치되어 있지 않음. Excel 설치 필요 |
| 특정 파일만 실패 | 암호 보호된 파일이거나, 다른 프로그램에서 이미 열려 있는 파일일 수 있음. 파일을 닫고 재시도 |
| 한글이 깨져 보임 | 발생하지 않아야 정상 (Excel 자체 렌더링 사용). 발생 시 원본 파일의 폰트가 PC에 설치되어 있는지 확인 |

# Spotfire(.dxp) → Excel 변환/검색 도구

TIBCO Spotfire를 실행하지 않고도 `.dxp` 분석 파일 안에 저장된 데이터를 바로
**Excel로 변환**하거나, **키워드로 검색해서 필요한 데이터만 추출**하는 Windows용
프로그램입니다.

## 핵심 특징

- **Spotfire 프로그램 불필요**: `.dxp` 파일을 Spotfire로 열지 않고, 파일 내부에
  저장된 데이터 테이블을 직접 읽어서 처리합니다. exe를 실행하는 PC에 Spotfire가
  설치되어 있지 않아도 됩니다. (Microsoft Excel도 필요 없습니다.)
- **전체 변환**: `.dxp` 안의 모든 데이터 테이블을 각각의 시트로 나누어 하나의
  Excel 파일로 변환합니다.
- **검색 후 추출**: 키워드를 입력하면 모든 데이터 테이블에서 해당 키워드가
  포함된 행만 찾아 별도의 Excel 파일로 추출합니다. 대용량 `.dxp`에서 필요한
  내용만 빠르게 뽑아낼 때 유용합니다.
- **일괄 처리**: 여러 `.dxp` 파일을 한 번에 선택하거나 폴더째로 추가해 순서대로
  처리할 수 있습니다.

## 동작 원리 및 제한 사항

Spotfire 7.0 이상에서 저장된 `.dxp` 파일은 내부적으로 ZIP 압축 패키지이며, 그
안에 데이터가 SBDF(Spotfire Binary Data Format)라는 형식으로 저장되어 있습니다.
이 도구는 `.dxp`를 열지 않고 그 내부 구조를 직접 읽어서 데이터 테이블을 찾아
Excel로 변환합니다.

다음의 경우는 지원되지 않습니다.
- Spotfire 7.0 이전의 구버전 바이너리 `.dxp` 형식 (ZIP 기반이 아님)
- 데이터가 외부 데이터베이스 연결로만 구성되어 파일 안에 실제 데이터가
  내장되어 있지 않은 경우 (이 경우 "데이터 테이블을 찾지 못했습니다"로 표시됩니다)

## 1. 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서:

```bat
build_spotfire_converter.bat
```

더블클릭하거나 명령 프롬프트에서 실행하면 됩니다. 완료되면
`dist\Spotfire_dxp_Excel_변환기.exe` 파일이 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해서 배포하면 됩니다. (배포받는 사람은 Python, Spotfire,
Excel 중 아무것도 설치할 필요가 없습니다.)

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build_spotfire_converter.bat`을 Windows PC에서 한 번 실행해 exe를 만들어야
> 합니다.

## 2. 사용 방법 (부서원)

1. `Spotfire_dxp_Excel_변환기.exe` 실행
2. **파일 추가...** 또는 **폴더 추가...** 로 처리할 `.dxp` 파일을 목록에 담기
3. 작업 방식 선택
   - **전체 데이터를 Excel로 변환**: 모든 데이터 테이블을 시트별로 변환
   - **키워드로 검색해서 해당 데이터만 추출**: 검색어(및 대소문자 구분 여부)를
     입력하면 일치하는 행만 추출
4. 저장 위치 선택 (원본과 같은 폴더 / 다른 폴더)
5. **시작** 클릭
6. 진행 로그에서 파일별 성공/실패 및 발견된 데이터 테이블 확인

각 `.dxp` 파일은 다음과 같이 변환됩니다.
- 전체 변환: `보고서.dxp` → `보고서_변환.xlsx` (테이블별 시트 + 요약 시트)
- 검색 추출: `보고서.dxp` → `보고서_검색결과.xlsx` (테이블별 검색 결과 시트 + 검색요약 시트)

## 3. 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python spotfire_dxp_converter.py
```

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "이 파일은 압축(zip) 기반 형식이 아닙니다" | Spotfire 7.0 이전 구버전 형식의 `.dxp`. 이 도구로는 지원되지 않음 |
| "이 파일에서 내장 데이터 테이블을 찾지 못했습니다" | 데이터가 외부 DB 연결로만 구성되어 있어 파일 안에 실제 데이터가 없음 |
| 시트 이름이 GUID(긴 영문/숫자 조합)로 나옴 | 파일 내부에서 테이블의 표시 이름을 찾지 못한 경우로, 데이터 자체는 정상 추출됨 |
| 'spotfire' 패키지가 설치되어 있지 않습니다 | `pip install -r requirements.txt` 재실행 필요 |
