# Office 파일 분할기

용량이 커서 **업로드·첨부·사내 시스템 적재가 안 되는 파일**을,
사용자가 정한 크기(예: 10MB) 이하의 여러 파일로 잘라 주는 부서 배포용 Windows 프로그램입니다.
exe 파일 하나만 나눠 주면 되고, 받는 사람은 Python 도 Office 도 설치할 필요가 없습니다.

![분할 크기를 지정해 파일을 나누는 화면](docs/screenshot.png)

## 핵심 특징

- **원하는 용량으로 분할**: 5MB, 10MB, 20MB… 원하는 숫자를 직접 입력하면 결과 파일이 모두 그 크기 이하가 됩니다.
- **크기를 실제로 확인해서 맞춤**: 압축률은 파일마다 다르므로, 저장한 뒤 실제 크기를 재서 넘치면 줄이고 남으면 더 담습니다. "10MB 이하"가 실제로 지켜집니다.
- **네 가지 형식 지원**: Excel(xlsx·xlsm) · Word(docx) · PowerPoint(pptx) · **PDF**
- **Office 설치 불필요**: 파일 형식을 직접 다루므로 Excel/Word/PowerPoint/Acrobat 이 없는 PC에서도 동작합니다.
- **원본 무손상**: 원본은 읽기만 하며 절대 수정하지 않습니다.
- **여러 파일 한 번에**: 파일을 여러 개 넣거나 폴더째 추가하면 차례대로 처리합니다.
- **간단한 배포**: exe 파일 하나만 전달하면 됩니다.

## 형식별로 어떻게 나누나요?

| 형식 | 나누는 단위 | 유지되는 것 | 주의할 점 |
|---|---|---|---|
| **xlsx / xlsm** | 시트 → (한 시트가 크면) 행 | 셀 값·글꼴·색·숫자 서식·열 너비·병합·머리글 반복 | 차트·그림·피벗은 빠집니다. 매크로(xlsm)는 포함되지 않고 결과는 xlsx로 저장됩니다 |
| **docx** | 문단·표 (문서 순서 그대로) | 글꼴·스타일·표·그림·머리글/바닥글 | 쪽 번호는 각 파일에서 다시 1쪽부터 시작합니다 |
| **pptx** | 슬라이드 | 레이아웃·마스터·테마·발표자 노트·애니메이션 | 슬라이드 번호는 각 파일에서 다시 매겨집니다 |
| **pdf** | 쪽(page) | 글꼴·이미지·목차(북마크)·주석 | 암호가 걸린 PDF 는 암호를 먼저 풀어야 합니다 |

> 엑셀은 **머리글(첫 줄)을 모든 결과 파일에 반복**해서 넣어 주므로, 나눠진 파일을
> 따로 열어도 어떤 열이 무슨 값인지 바로 알 수 있습니다. (옵션으로 끌 수 있음)

## 1. 실행파일(exe) 빌드하기 (담당자 1회 작업)

Windows PC + Python 3.9 이상이 설치된 환경에서 **`build_splitter.bat` 을 더블클릭**하면 됩니다.
완료되면 `dist\Office_파일_분할기.exe` 가 생성됩니다. **이 exe 파일 하나만**
부서원들에게 복사해 주면 됩니다.

배치 파일은 Python 을 찾아 `build_exe.py` 를 실행하는 역할만 하므로,
명령 프롬프트에서 직접 실행해도 결과는 같습니다.

```bat
python build_exe.py              :: 실행파일 만들기
python build_exe.py --dry-run    :: 실제 빌드 없이 계획만 확인
```

Python 이 설치되어 있지 않으면 설치 안내가 화면에 표시되고, 사내망이라 pip 설치가
막힌 경우에는 이미 설치된 패키지로 계속 진행합니다.

> 이 저장소(리눅스 컨테이너)에서는 Windows용 exe를 직접 빌드할 수 없으므로,
> `build_splitter.bat` 을 Windows PC에서 한 번 실행해 exe를 만들어야 합니다.

## 2. 사용 방법 (부서원)

1. `Office_파일_분할기.exe` 실행
2. 나눌 파일을 **끌어다 놓거나** 위쪽 영역을 클릭해서 선택 (폴더째 추가도 가능)
3. **분할 크기** 입력 — 숫자를 직접 쓰거나 `5MB` `10MB` `20MB` 버튼 클릭
4. **저장 위치** 선택 (원본과 같은 폴더 / 다른 폴더 지정)
5. **파일 나누기** 클릭
6. 끝나면 **결과 폴더 열기** 로 결과 확인

결과 파일은 `원본이름_분할` 폴더 안에 `원본이름_part01`, `원본이름_part02` …
형태로(확장자는 원본과 동일) 만들어집니다. (폴더로 묶는 것이 싫으면 옵션에서 끄면 됩니다)

### 세부 옵션 (Excel)

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 머리글(첫 줄)을 모든 파일에 반복 | 켬 | 각 결과 파일 맨 위에 원본 첫 줄을 넣어 줍니다 |
| 수식을 계산된 값으로 저장 | 켬 | 파일을 나누면 다른 시트를 참조하는 수식이 깨지므로, 계산된 값으로 저장합니다 |
| 처리 방식: 자동 / 서식 유지 / 빠르게 | 자동 | **자동**은 파일이 15MB를 넘으면 메모리·속도를 위해 서식 없이 데이터만 옮깁니다. 서식이 꼭 필요하면 **서식 유지**를 고르세요 |

## 3. 개발/테스트용으로 직접 실행하기

```bat
pip install -r requirements.txt
python office_file_splitter.py
```

분할 기능만 따로 검증하려면:

```bat
python tests\test_splitter_core.py    :: 실제 파일을 만들어 나누고 내용 보존까지 확인
python tests\test_ui_smoke.py         :: 화면을 띄워 추가~완료까지 자동으로 눌러 봄
python tests\test_batch_files.py      :: .bat 파일이 cmd.exe 에서 깨지지 않는지 검사
```

분할 기능은 `splitter_core.py` 에 화면과 분리되어 있어, 다른 스크립트에서
그대로 가져다 쓸 수도 있습니다.

```python
from splitter_core import SplitOptions, split_file, MB

result = split_file("대용량.pdf", SplitOptions(max_bytes=10 * MB))
print(result.parts)
```

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "이미 지정한 용량 이하입니다" | 나눌 필요가 없는 파일입니다. 분할 크기를 더 작게 잡으면 나눌 수 있습니다 |
| "옛날 형식(.xls/.doc/.ppt)은 지원하지 않습니다" | Office에서 **다른 이름으로 저장** → xlsx/docx/pptx 로 바꾼 뒤 사용하세요 |
| "암호가 걸린 PDF 는 나눌 수 없습니다" | PDF 뷰어에서 암호를 푼 사본을 만든 뒤 사용하세요 |
| 결과 파일 1개가 지정 용량을 넘음 | 슬라이드 1장·PDF 1쪽·행 1줄이 그 자체로 용량을 넘는 경우입니다 (대개 큰 이미지). 진행 상황에 어느 슬라이드/쪽/행인지 표시됩니다 |
| 엑셀에서 차트·그림이 사라짐 | 정상 동작입니다. 차트·그림까지 유지해야 한다면 원본에서 해당 시트만 따로 저장해 주세요 |
| 매우 큰 엑셀에서 시간이 오래 걸림 | 처리 방식을 **빠르게** 로 두면 훨씬 빠릅니다 (서식 제외) |
| 드래그 앤 드롭이 안 됨 | 클릭해서 파일을 고르면 됩니다. (드래그는 tkinterdnd2 가 포함되어 빌드된 경우에만 동작) |
| bat 실행 시 "내부 또는 외부 명령…" 오류 | 배치 파일이 깨진 경우입니다. 아래 **배치 파일 수정 규칙**을 참고하세요. `python build_exe.py` 로 직접 빌드해도 됩니다 |

## 파일 구성

```
office_file_splitter.py   분할기 본체 (화면 + 실행 흐름)
office_splitter_ui.py     분할기 화면 구성 요소 (버튼·토글·진행바 등)
splitter_core.py          분할 엔진 (화면과 분리, 단독 사용 가능)
build_exe.py              실제 빌드 작업 (한글 안내 포함)
build_splitter.bat        exe 빌드 (build_exe.py 를 부르는 역할만)
docs/help_python_ko.txt   Python 미설치 시 보여 줄 한글 안내
.gitattributes            .bat 을 항상 CRLF 로 받도록 지정
tests/                    자동 검증 스크립트
```

## 배치 파일(.bat) 수정 규칙 — 중요

cmd.exe 는 `.bat` 파일을 UTF-8 이 아니라 **OEM 코드페이지(한국어 Windows 는 949)** 로 읽습니다.
그래서 아래 세 가지가 있으면 줄이 깨지면서
`'...'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다` 오류가 납니다.

| 하지 말 것 | 이유 | 대신 |
|---|---|---|
| 배치 파일에 한글 쓰기 | CP949 로 잘못 읽혀 깨짐 | 한글 메시지는 `build_exe.py` 에 두기 |
| LF 줄바꿈으로 저장 | 리눅스/맥에서 만들면 기본값. cmd 가 줄을 잘못 끊음 | **반드시 CRLF** (`.gitattributes` 로 강제) |
| 줄 끝에 `^` (줄 연속) | 위 두 문제와 겹치면 다음 줄이 명령으로 실행됨 | 한 줄로 쓰거나 파이썬으로 옮기기 |

`python tests/test_batch_files.py` 를 실행하면 이 규칙을 자동으로 검사합니다.
배치 파일을 고친 뒤에는 반드시 한 번 돌려 보세요.
